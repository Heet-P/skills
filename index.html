How they work

Just prompts. Commands inside.

A skill is a Markdown file your agent reads when it's relevant. Mine come with commands, so you ask for exactly the piece you want instead of explaining it from scratch.

01

Add it to any project.

One npx line copies a folder of Markdown into your project. Nothing to import, no keys, no account. Delete the folder and it's gone.

02

Type the command you need.

/scrollfx smooth sets up smooth scroll for the whole site. /web3d camera makes the camera fly as you scroll. /demovideo launch plans and builds a launch film.

03

Learned from real builds.

Each rule is something that broke or looked off in one of my projects: leaked scroll triggers, 3D scenes that melted laptops, music that drifted off the cuts.

How I use them

Install once. Then just ask.

Add a skill with npx. After that, either type its command or just describe what you want. The agent loads the skill on its own when the task matches.

~/my-hackathon-app · claude code
$ npx skills add Heet-P/skills --skill demovideo
added skill: demovideo

> /demovideo launch 50 seconds, submission on Sunday
reading README, landing page, brand tokens…
plan: intro 4s · problem 6s · 3 features · proof 8s · close 8s @ 120 BPM

✓ remotion/ added · timeline.ts · kit.tsx · 7 scenes · score.ts
✓ npm run video to preview · npm run video:render for 1080p + 4K

>
i.

Add the skill with npx.

npx skills add Heet-P/skills --skill scrollfx drops it into .claude/, .cursor/, or wherever your agent reads skills from. Take only what you need.

ii.

Run a command, or just describe it.

/web3d scene a slowly rotating city at night works. So does "make the hero 3D". With no command, the skill asks what you want and suggests a few that fit.

iii.

Run the audit before you ship.

/scrollfx audit and /web3d audit check the code against each skill's checklist (cleanup, reduced motion, mobile) and fix what fails.
